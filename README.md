# E-commerce-Sales-Analysis_Python
# Ecommerce Sales Analysis Using Python

## Project Overview
This project focuses on analyzing e-commerce sales data using Python to identify sales trends, profitability, customer behavior, and product performance. The project includes data cleaning, preprocessing, Exploratory Data Analysis (EDA), and data visualization to generate meaningful business insights.

## Objectives
- Clean and preprocess raw e-commerce data.
- Perform Exploratory Data Analysis (EDA).
- Analyze sales and profit performance.
- Identify top-performing products, categories, and regions.
- Understand customer purchasing patterns.
- Visualize important business trends and insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Information
- Dataset: E-commerce Sales Dataset
- Original Records: 100,500 rows
- Columns: 16
- Data includes order details, customer information, product categories, sales, profit, quantity, discounts, and shipping costs.

## Data Cleaning & Preprocessing
The following data-cleaning activities were performed:
- Removed duplicate records.
- Handled missing values.
- Corrected inconsistent data formats.
- Identified and handled invalid sales and discount values.
- Corrected invalid order and shipping dates.
- Addressed inconsistent text formatting.
- Handled extreme shipping-cost values.

## Exploratory Data Analysis (EDA)
Performed detailed analysis to understand:
- Sales and profit distributions.
- Regional sales performance.
- Category and sub-category performance.
- Top 10 products by sales.
- Customer segment analysis.
- Monthly and quarterly sales trends.
- Discount impact on profitability.
- Shipping cost analysis.
- Payment mode distribution.
- Customer purchasing patterns.

## Visualizations
Created 20 visualizations using Matplotlib and Seaborn, covering:
- Sales and profit distributions.
- Regional and category-wise performance.
- Product and customer insights.
- Monthly and quarterly trends.
- Discount and shipping analysis.
- Business performance comparisons.

## Project Files
- `Ecommerce_Sales_Analysis.ipynb` – Python analysis and visualizations.
- `ecommerce_dirty_dataset.csv` – Original dataset.
- `ecommerce_cleaned_dataset.csv` – Cleaned dataset.
- `Executive_Summary.pdf` – Project summary and key insights.
